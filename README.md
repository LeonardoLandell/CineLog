### Sobre o Projeto
**CINELOG** é um projeto de nível profissional focado em performance e refinamento visual. A aplicação integra dados de APIs externas (TMDB para filmes/séries e Jikan para animes) com uma arquitetura serverless robusta e persistência em nuvem utilizando Turso. O design system foi totalmente customizado aplicando a proporção autoral 60-30-10 para os modos Day (Chalk White, Onyx Black, Mint Rush) e Dark (Onyx Black, Chalk White, Electric Violet).

###  Tecnologias
-> **Front-end:** Vite, TypeScript, Vanilla SPA Architecture, CSS Custom Properties (Design System autoral)
-> **Back-end:** Vercel Serverless Functions (`/api`)
-> **Banco de Dados:** Turso (libSQL / SQLite distribuído)
-> **APIs Integradas:** TMDB API & Jikan API (MyAnimeList)
