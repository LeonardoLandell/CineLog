# 🎬 CineLog

Plataforma moderna para descoberta de filmes, séries e animes, desenvolvida com foco em performance, experiência de usuário imersiva e design editorial.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** TypeScript
* **Bundler & Build:** Vite & Esbuild
* **Estilização:** CSS Moderno (Variáveis CSS, Flexbox/Grid, Glassmorphism)
* **APIs Externas:** TMDB API (Filmes e Séries) & Jikan API (Animes)
* **Base de Dados / Armazenamento:** Turso (`@libsql/client`)

## ✨ Funcionalidades Principais

* **Catálogo Multimédia:** Secções dedicadas para Filmes em Cartaz, Populares, Séries em Alta e Animes Recentes.
* **Modo Dia / Noite:** Alternância fluida de temas adaptada ao conforto visual.
* **Detalhes e Modais Interativos:** Informações detalhadas, pontuações, sinopses e dados de lançamento.
* **Performance Otimizada:** Carregamento priorizado de ativos (LCP otimizado), pré-conexão com servidores externos e renderização diferida para máxima fluidez em dispositivos móveis e desktops.
